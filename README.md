# teams-feature-test

A repository for trying out GitHub collaboration with Copilot in Microsoft Teams.

## Current status

This repository currently contains only this README. There is no application
code, dependency installation, build process, or test suite yet.

## Getting started

With Git installed and access to the repository, clone it:

```bash
git clone https://github.com/lingfangggg/teams-feature-test.git
cd teams-feature-test
```

No additional setup is required at this stage.
